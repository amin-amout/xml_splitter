# ✅ Maven Build Setup Complete!

## What Changed

Your XML2Hive project now uses **Maven** as the standard build tool instead of custom shell scripts with `scalac`. This provides:

- ✅ **Dependency Management** - Automatic download of Scala compiler and libraries
- ✅ **IDE Integration** - Works seamlessly with IntelliJ, VS Code (Metals), Eclipse
- ✅ **Reproducible Builds** - Same build on any machine
- ✅ **Standard Tooling** - Industry-standard Java/Scala build system

## Quick Start

### 1. Build the Project

```bash
cd /home/droidlulz/projects/xml2hive

# Clean and build
mvn clean package

# Output: target/xml2hive.jar (5.2MB)
```

### 2. Test It

```bash
# Run XML splitter
java -cp target/xml2hive.jar XmlStreamingSplitter \
  examples/sample-data.xml \
  test-chunks \
  Order \
  2

# Check output
ls -lh test-chunks/
```

### 3. Run on Real Data

```bash
# Split your 30GB XML
java -Xmx4g -cp target/xml2hive.jar XmlStreamingSplitter \
  /path/to/huge-file.xml \
  /output/chunks \
  Record \
  1000

# Process with Spark
spark-submit \
  --master yarn \
  --deploy-mode cluster \
  --executor-memory 8G \
  --executor-cores 4 \
  --num-executors 10 \
  --packages com.databricks:spark-xml_2.12:0.17.0 \
  --class XmlToParquetPipeline \
  target/xml2hive.jar \
  hdfs:///data/chunks \
  hdfs:///data/output \
  Record
```

## Key Maven Commands

```bash
# Clean build artifacts
mvn clean

# Compile only (no JAR)
mvn compile

# Create JAR
mvn package

# Skip tests (faster)
mvn package -DskipTests

# Show dependency tree
mvn dependency:tree

# Update dependencies
mvn clean install -U

# Verbose output
mvn package -X
```

## Troubleshooting

### Maven Not Found

```bash
# Ubuntu/Debian
sudo apt-get install maven

# macOS
brew install maven

# Check version
mvn -version  # Should be 3.6+
```

### Build Fails with "bad constant pool"

This was already fixed. The issue was Java 23 compatibility with Scala 2.12.15. We upgraded to Scala 2.12.18.

### OutOfMemory During Build

```bash
export MAVEN_OPTS="-Xmx2g -Xms512m"
mvn clean package
```

### Clean Everything

```bash
# Remove all build artifacts
mvn clean

# Remove Maven cache
rm -rf ~/.m2/repository/com/example/xml2hive
rm -rf ~/.m2/repository/net/alchim31/maven/scala-maven-plugin

# Rebuild from scratch
mvn clean package
```
